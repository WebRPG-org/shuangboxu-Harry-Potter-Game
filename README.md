## 📖 项目简介

本项目是一款以魔法世界为背景的原创游戏作品，融合了剧情叙事、关卡探索与互动玩法，注重沉浸感与整体游戏体验。

游戏由 **NORTH LAKE** 游戏开发小组完成。NORTH LAKE 是一个充满创意与活力的独立游戏开发团队，由多名成员协作完成，涵盖项目管理、程序开发、关卡设计、音效音乐、剧情文本以及测试等多个方向。

**NORTH LAKE** 这一名称象征着团队在开发过程中所坚持的专注、合作与创新精神。
